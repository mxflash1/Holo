# Product

## Register

product

## Users

A MacBook user who moves between home, work and nearby desks, using left/right desk taps to trigger local actions. The app usually stays in the menu bar and is opened briefly for setup or adjustments.

## Product Purpose

Make calibrated desk tapping dependable and easy to manage across environments. Saved desks, reusable sounds to ignore, location switching and shortcut configuration should be visible destinations rather than hidden additions.

## Brand Personality

Native, calm, practical. Follow the macOS appearance and system typography. Prefer direct labels and compact controls to ornamental dashboards.

## Anti-references

Avoid science-fiction visual treatments, decorative gradients, excessive cards, oversized windows with sparse navigation, and burying everyday controls inside unrelated calibration flows.

## Design Principles

- Give everyday features clear, stable navigation.
- List saved desks directly in the sidebar; keep desk calibration data separate.
- Make microphone state and listening controls easy to find.
- Put configuration in Settings, including a persistent editable global shortcut.
- Retain experimental and debugging tools under Advanced Settings until deletion is explicitly approved.

## Accessibility & Inclusion

Use native SwiftUI/AppKit controls, accessible labels, keyboard navigation, system light/dark appearance and reduced-motion support. Show shortcut conflicts clearly and keep the previous working shortcut if replacement fails.

## Approved layout

Overview, My Desks, Shared Sounds, Locations, Actions, Settings. Accuracy checks belong with desk management. Saved desks occupy the sidebar below navigation. Settings and listening state stay at the bottom. No saved user data or experimental functionality is to be deleted.
